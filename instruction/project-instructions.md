# Project Instructions

## Project
TaskFlow — Simple Todo List Application.

## Scope
Build a frontend-only Todo application using HTML, CSS, Vanilla JavaScript, and LocalStorage.

## Features
- Add, edit, delete, and view tasks.
- Mark tasks complete or active.
- Filter All, Active, and Completed.
- Persist tasks using LocalStorage.
- Responsive dark UI.

## Development Rules
- Keep implementation simple.
- Reuse existing project files.
- Do not introduce unnecessary dependencies or frameworks.
- Follow the approved architecture and implementation plan.
- Do not implement unapproved features.
- Ask for approval before modifying files.
