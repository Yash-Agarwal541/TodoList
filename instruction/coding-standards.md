# Coding Standards

## HTML
- Use semantic HTML5 elements.
- Keep markup clean and accessible.
- Use meaningful IDs and class names.

## CSS
- Use simple, reusable CSS.
- Keep styling in `css/style.css`.
- Maintain consistent spacing and colors.
- Support desktop, tablet, and mobile screens.

## JavaScript
- Use Vanilla JavaScript.
- Keep code readable and modular.
- Use `const` and `let` appropriately.
- Use meaningful variable and function names.
- Avoid unnecessary complexity.
- Store and retrieve tasks using LocalStorage.
- Handle empty inputs and invalid operations.

## General
- Avoid duplicate code.
- Do not add unnecessary libraries.
- Preserve existing functionality.
- Test changes before reporting completion.
